# Northstar Kanban

A simple, client-rendered Kanban board for moving product work forward.

## Features

- One board with five renameable columns
- Sample cards when the app opens
- Add, delete, and drag cards between columns
- In-memory state; changes reset when the page reloads

## Run locally

```bash
cd frontend
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Checks

```bash
cd frontend
npm test
npm run test:e2e
npm run lint
npm run typecheck
npm run build
```
